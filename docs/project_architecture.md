# 光线游戏：项目架构与关卡制作流程

更新：2026-10-26。本页描述当前代码；概念定义见根目录 CONTEXT.md。

## 先分清三个互相独立的维度

| 维度 | 取值 | 决定什么 |
| --- | --- | --- |
| 关卡发布状态 | 草稿 / 已发布 | 是否出现在“开始游戏” |
| 关卡玩法 | 固定关 / 限定搭建关 | 玩家能否摆放库存、连接获准电线 |
| 本次运行入口 | 编辑器创作 / 玩家预览 / 正式游玩 | 谁控制输入、能否写进度和发奖励 |

“已发布”不等于“正在正式游玩”。已发布关卡从工坊预览，依然不能获得金币、升级虚线或记录正式进度。

## 从入口到玩法

```text
主菜单
├─ 开始游戏 → 章节/关卡 → 正式游玩
│                            ├─ 固定关：瞄准 → 发射 → 机关动作
│                            └─ 搭建关：搭建 ⇄ 瞄准/发射 → 机关动作
│                                  完成 → 50 金币 + 进度 → 下一关/返回章节
└─ 关卡工坊
   ├─ 编辑 → 编辑器验证 ⇄ 编辑（保留手动调整，不记录模拟位移）
   └─ 玩家预览 → 与玩家相同的玩法限制 → 预览结算/返回工坊
```

编辑器的“试玩”“实时验证”已合并为一个“验证”。玩家搭建栏的“开始试射 / 返回搭建”是同一关卡内部切换阶段，不是另一套关卡类型。

直接在 Godot 中运行某个关卡，默认按玩家预览处理。需要验证正式进度时，应从主菜单的“开始游戏”进入。

## 生命周期与数据边界

### 编辑器验证

1. 挂载关卡前声明创作上下文。LevelManager 不创建 PlayerBuilder 或结算屏，不接收游戏快捷键，不连接胜利流程。
2. 进入验证：保存设计快照，运行光线、重力、机关；编辑器负责输入。
3. 手动调整已有元件/电线，单独记录属性修改；期间不允许增删结构。
4. 退出：取消光线发射并释放暂停，恢复快照，再应用手动修改。
5. 重力下落、机关动画位移和鼠标跟随的临时瞄准不保存；拖动光源或修改角度输入框属于手动修改。
6. 这些手动修改可以作为一个撤销步骤整体撤回。

不再依靠“先运行游戏 UI，再延迟 free 掉 UI”中和编辑器关卡，避免悬空引用和 Esc 输入互相抢占。

### 玩家预览与正式游玩

- 目录提交与关卡路径绑定的一次性运行凭证；LevelManager 加载时取出。
- 工坊预览、直接运行场景或凭证路径不匹配时，不获得正式进度权限。
- 正式奖励同时要求：正式入口、目录中的官方 ID/路径匹配、关卡已解锁。
- 重玩沿用入口；下一关使用正式入口；返回会清除待使用凭证。
- LevelManager.completed 表示本次关卡已完成（预览也会发出）；GameEvents.level_completed 只用于正式游玩的全局通知。
- 预览与正式玩法共用同一 PlayerBuilder、LightSystem、ActionLink，不复制玩法代码。

## 如何制作带电线的限定搭建关

1. 工坊编辑 → “关卡玩法设置”选限定搭建关。
2. 设置允许玩家带入的元件和数量；不提供的元件不出现在玩家左栏。
3. 设置电线数量。只有数量还不够，必须提供可出线的开关和可接线的目标。
4. 选中预置开关，勾选“允许玩家从此预置开关接线”；或者在库存提供触发开关/压力传感器。
5. 选中预置目标，勾选“允许玩家给此预置机关接线”；玩家自己放置的可接线元件也可作为目标。
6. 接线开放不改变固定权限：预置元件依然不能由玩家移动、缩放、旋转或回收。
7. 点击“检查关卡”。配置错误不阻止保存草稿，但会阻止发布。
8. 先用“验证”检查机关动作，再保存并从工坊“玩家预览”验证真实玩家限制。

玩家可点击开关后在右侧选择“从这个开关接线”，再点击目标；也可以拖动开关右侧端口到目标。Shift+拖开关仍作为快捷方式保留。

一个目标只允许一条电线，避免多个 Tween 抢同一位置。新电线默认位移和旋转均为 0；右侧设置终点、角度、标准速度和触发后持续往返。

地形分为“机关墙体”和“固定遮光墙”：两者都挡光，只有机关墙体可接电线。固定遮光墙即使由玩家放置，也不能作为电线目标。

### 当前草稿注意事项

第 8 关有电线数量，但缺少可用开关，系统会报告配置问题。第 9 关按设计意图开放两个预置开关出线，并只允许镜面与 Wall2 接线；这些预置物体仍不可由玩家直接移动、旋转或回收。系统不会自动把其他固定元件解锁。

## 验证与防回归

PowerShell 在项目目录运行：

```powershell
.\tools\dev.bat 40
```

测试必须同时满足退出码正常、出现 TEST RESULT: PASS、无 SCRIPT ERROR/ERROR。不能只看最后的 PASS。

核心覆盖：

- 编辑器多次进入/退出验证、重力/机关状态恢复、手动属性保留、撤销。
- 编辑器嵌入搭建关时不创建玩家控制器；Esc 不退出编辑器。
- 发射中退出验证不遗留全局暂停。
- 预览正式关也不发金币、不消耗金币、不提供下一关；正式入口正常结算。
- 接线权限、数量上限、重复目标、真实 Viewport 鼠标端口拖线、按钮接线、拆线信号清理。
- 动作参数输入框与真实数值一致；搭建 → 发射 → 返回保留玩家布置。
- 原有反射、折射、透镜、传送门、融冰和示例关卡解法测试。

新增 bug 的处理顺序：明确入口和阶段 → 记录最短操作步骤 → 加能复现的测试 → 修共用规则 → 重跑相关测试和全套测试 → MCP 操作与报错检查。

MCP 需要编辑器插件与 MCPRuntime 两端均连接。本地开发已注册运行时助手；导出给玩家前需关闭 MCP 插件并确认移除 MCPRuntime 自动加载，不能把开发控制入口留在发布包里。
